# Projects

## Projects within EIDF

Every EIDF project can request that a project with the ECIR is created for them. This project will be private to the project.

### Project Quota

Each project will be given N GiB of storage for images to use.

Request for increase should be submitted as a request via the [EIDF Portal](https://portal.eidf.ac.uk).
